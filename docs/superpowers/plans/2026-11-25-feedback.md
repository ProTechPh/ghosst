# Private App Feedback Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let signed-in users submit private ratings/comments to the Ghosst team and view their own submission history, reusing the existing website feedback table and admin page.

**Architecture:** Add a `source` discriminator to `feedbacks`; app rows are always `source='app'` and `status='hidden'`. New authenticated API routes validate and rate-limit submissions. The existing admin page displays them but cannot publish them.

**Tech Stack:** Flutter/Dart, PHP 8/PDO MySQL, existing website admin UI.

**Spec:** `docs/superpowers/specs/2026-11-25-social-features-design.md` (approved 2026-11-25), sections 11, 14–15, 17–19.

**Depends on:** existing `feedbacks` table and `ghosst-web/admin/feedbacks.php`.

## Global Constraints

- App feedback is permanently private; only `source='website'` rows may become public.
- Comment is trimmed, 10..1000 UTF-8 characters; rating is integer 1..5.
- Maximum 5 app feedback submissions per rolling 24 hours per user.
- No image upload in v1; `image_path` stays null.
- HTTP calls stay in `lib/services/worker_backend.dart`; models live in `lib/services/models.dart`.
- Tests do not need MySQL or network; PHP tests exercise pure validators.
- Do not manually bump the build number or push to `main`.

## Review Focus

1. Admin accidentally publishes private app feedback → Show action disabled and public queries filter `source='website'`; pinned in Task 1 source-level/PHP tests.
2. Empty, 9-character, 1001-character, or HTML-tag comment → 400, no DB write; pinned in Task 2 tests.
3. Sixth submission in 24 hours → 429 with retry guidance; pinned in Task 2 validator/rate-window tests.
4. App feedback from a deleted account → row removed, website reviews untouched; pinned in Task 5 PHP/source tests.
5. API failure after Submit → draft retained and Retry works; pinned in Task 4 widget tests.
